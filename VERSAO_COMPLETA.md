# Versão completa do CONFINAMENTO Online

A versão completa está preparada no pacote `CONFINAMENTO_ONLINE_RENDER_PRONTO.zip` compartilhado na conversa. Inclui autenticação, salas, equipes, provas, Arca, formação da Roça, votação, Fazendeiro, bots e imagens.

**Atenção:** o código publicado no repositório ainda é uma prévia simplificada. Não confundir o deploy da prévia com a versão completa. Para publicar o projeto completo, substituir `server.js`, `package.json` e a pasta `public/` pelos arquivos extraídos do pacote, preservando a estrutura de diretórios. O Render está configurado para publicar a branch `main` automaticamente.

Dados salvos em arquivo local no plano gratuito do Render não são persistentes entre reinicializações; a implantação definitiva precisa de armazenamento persistente e revisão de segurança.
